# 🤖 SigmaGPT

SigmaGPT is a full-stack AI chatbot built with the MERN stack and Google's Gemini API. It features secure user authentication, persistent chat history, and multi-thread conversations.

## 🚀 Live Demo

- **Frontend:** https://sigmabot-sakshtapatils-projects.vercel.app/
- **Backend:** https://sigmagpt-snv0.onrender.com/

## ✨ Features

- 🔐 Secure user authentication with JWT
- 🤖 AI-powered chat using Google Gemini API
- 💬 Multi-thread conversations
- 📝 Persistent chat history
- 🗑️ Delete chat threads
- 📄 Markdown & syntax-highlighted code responses

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- React Router
- Context API
- CSS

**Backend**
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcrypt

**AI**
- Google Gemini API
